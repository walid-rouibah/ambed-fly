## About

Ambed Fly adds a small animated fly to your GNOME desktop.

It naturally wanders around the screen, changes direction smoothly, reacts to mouse movement, and responds to moving windows.

Designed to be lightweight and unobtrusive, Ambed Fly adds a subtle touch of life to the desktop without getting in the way.

---

## Features

* Animated fly with multiple animation frames
* Natural wandering movement
* Smooth direction changes
* Mouse interaction
* Reaction to moving windows
* Lightweight and unobtrusive
* Minimal design
* Native GNOME Shell extension

---

## Compatibility

Ambed Fly supports **GNOME Shell 45 and later**.

It is designed to work across Linux distributions using a compatible version of GNOME Shell.

## Installation

### GNOME Extensions

The recommended and easiest way to install Ambed Fly is through the official GNOME Extensions website.

<p align="center">
  <a href="https://extensions.gnome.org/extension/10787/ambed-fly/">
    <img src="https://img.shields.io/badge/Install%20Ambed%20Fly-4A86CF?style=for-the-badge&logo=gnome&logoColor=white" alt="Install Ambed Fly">
  </a>
</p>

Open the page, click **Install**, and enable the extension.

No terminal or manual installation is required.

### Manual Installation

For users who prefer installing from the source code:

1. Download the repository from GitHub.
2. Extract the ZIP file.
3. Open the extracted project folder.
4. Right-click inside the folder and choose **Open in Terminal**.
5. Run:

```bash
bash install.sh
```

The installer automatically installs the extension, copies the required files, and compiles the GNOME settings schema.

After installation, open **GNOME Extensions** and enable **Ambed Fly**.
